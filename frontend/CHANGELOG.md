# Список изменений

## Реализованные функции

### 1. ✅ Перенос времени на следующий день
- Уже реализовано в `dayTimeline.ts` - время больше 00:00 корректно переносится на следующий день
- Смены типа `22:00–06:00` отображаются как два сегмента: `22:00–24:00` и `00:00–06:00`

### 2. ✅ Навигация по дням в диаграмме
- Добавлены кнопки "←" и "→" для переключения между днями
- Расположены слева и справа от табов "Диаграмма/Список"
- Используют функцию `shiftDay(offset)` для переключения

### 3. ✅ Режим "Один день" vs "Пресет"
- Добавлены два режима в форме добавления смены:
  - **"Один день"** - добавляет смену только на выбранный день
  - **"Пресет"** - добавляет смены по шаблону (еженедельно, циклично и т.д.)
- Переключение между режимами через кнопки сверху формы

### 4. ✅ Список пресетов на отдельном табе
- Добавлен таб "Пресеты" в настройках
- Показывает встроенные и пользовательские пресеты
- Отображает время дневных и ночных смен для каждого пресета

### 5. ✅ Удаление пресетов и дней
- Пользовательские пресеты можно удалить из таба "Пресеты"
- Отдельные смены удаляются через список смен

### 6. ✅ Группы на отдельном табе
- Добавлен таб "Группы" в настройках
- Управление друзьями: переименование, смена цвета, удаление
- Показывает всех людей с их цветами

### 7. ✅ Пресеты на отдельном табе
- Реализовано в компоненте `PresetsSection.vue`
- Отдельное отображение встроенных и пользовательских пресетов

### 8. ✅ Исправлена проблема с потерей данных при обновлении
- Добавлена версионность для localStorage
- Миграция данных при обновлении приложения
- Сохранение labels, colors, hidden и других настроек

### 9. ✅ Исправлен баг с праздниками
- Праздники теперь корректно отображаются для всей сетки календаря
- Включая дни из соседних месяцев, видимые в календаре

### 10. ✅ Исправлено изменение смены
- При редактировании смены старая версия корректно удаляется
- Изменение времени, заметки или любого поля корректно обновляет смену

## Структура изменений

### Измененные файлы:
1. `frontend/src/components/ShiftEditor.vue` - добавлена навигация по дням
2. `frontend/src/components/shift/ShiftForm.vue` - режимы "Один день"/"Пресет"
3. `frontend/src/stores/schedule.ts` - версионность localStorage
4. `frontend/src/composables/useSchedule.ts` - исправлен баг с праздниками
5. `frontend/src/pages/SettingsPage.vue` - табы для групп и пресетов

### Новые файлы:
1. `frontend/src/components/settings/GroupsSection.vue` - управление группами
2. `frontend/src/components/settings/PresetsSection.vue` - упр��вление пресетами
