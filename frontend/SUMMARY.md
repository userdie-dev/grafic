# Краткая сводка изменений

## Выполнено

### ✅ 1. Перенос времени на следующий день
- TimePicker теперь позволяет выбирать время до 48:00 для поля "Конец"
- Автоматический перенос на следующий день (25:00 → следующий день 01:00)

### ✅ 2. Свайпы для навигации
- Свайп влево → следующий день
- Свайп вправо → предыдущий день
- Реализован�� через `@vueuse/core` (`useSwipe`)

### ✅ 3. Группы на нижнем баре
- Новая страница с полным функционалом управления группами
- Создание, редактирование, удаление групп
- Добавление/удаление участников
- Группы отображаются с иконкой 👥, участники скрыты из индивидуального списка
- Смены участников агрегируются под именем группы

### ✅ 4. Пресеты на нижнем баре
- Новая страница для управления пресетами
- Создание пользовательских пресетов с:
  - Разными типами повторения (один раз, еженедельно, цикл, дни недели)
  - Настройкой времени дневных/ночных смен
  - Поддержкой времени следующего дня
- Встроенные + пользовательские пресеты
- Сохранение в localStorage

### ✅ 5. Сохранение в localStorage
- Группы сохраняются в `schedule` store
- Пресеты сохраняются в `presets` store
- Автоматическое сохранение через `@vueuse/core`

### ✅ 6. Подключение к production
- Настроено на `https://grafic-rose.vercel.app/`

## Навигация

Теперь 5 пунктов в нижнем баре:
1. **Календарь** - основной календарь с группами
2. **Группы** - управление группами людей
3. **Пресеты** - управление шаблонами смен
4. **Поделиться** - код для добавления друзей
5. **Настройки** - настройки приложения

## Запуск

```bash
cd frontend
npm run dev  # localhost:5174
```

Dev-сервер уже запущен!
