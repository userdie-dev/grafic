## 📊 Архитектура

### Навигация (5 пунктов в нижнем баре)
1. **Календарь** - основной календарь с группами и людьми
2. **Группы** - создание и управление группами
3. **Пресеты** - создание и управление шаблонами смен
4. **Поделиться** - код для добавления друзей
5. **Настройки** - настройки приложения

### Группы
```
Группа:
├─ Название
├─ Цвет
└─ Участники[]
   └─ Их смены агрегируются под именем группы
```

- Отображаются с иконкой 👥
- Участники скрыты из индивидуального списка
- Смены всех участников показываются под именем группы

### Пресеты
```
Пресет:
├─ Название
├─ Описание
├─ Тип повторения (once/weekly/cycle/weekdays)
├─ Параметры повторения
├─ Дневная смена (начало, конец)
└─ Ночная смена (начало, конец)
```

- Встроенные: неизменяемые, в коде
- Пользовательские: CRUD, в localStorage
